# Data Collection - Web Scraping

Scripts that fetch and scrape data from web pages using the Python
`requests` package: making HTTP requests, handling headers, timeouts,
status errors, and extracting HTML content.

## Requirements
- Ubuntu 20.04 LTS, Python 3.9
- `requests` package
- pycodestyle 2.11.1
- All files start with `#!/usr/bin/env python3` and are executable
- A README.md at the root of the project is mandatory

## Tasks
| File | Description |
|------|-------------|
| `0-fetch_html.py` | `fetch_html(url, headers={}, timeout=10)` — fetch a page and return its HTML, raising on status >= 400 |
